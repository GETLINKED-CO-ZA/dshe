D-SHE website set
1. Open index.html in a browser to preview. Works offline; forms fall back to opening an email.
2. Edit js/config.js: email, products and prices.
3. Go live: push to GitHub, import into Vercel, add env vars BREVO_API_KEY, SENDER_EMAIL, NOTIFY_EMAIL (PAYSTACK_SECRET_KEY later).
4. Link or embed from Google Sites, e.g. shop.safetydshe.co.za.
